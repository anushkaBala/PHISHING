# PHISH
A Comprehensive AI-Powered Phishing Detection and Prevention Platform
PISH is a Python-driven application that integrates with a Gmail account to fetch emails and determine whether they are phishing or legitimate using a pre-trained machine learning algorithm.  

### Key Features:  
- **Email Fetching**: Utilizes IMAP to access Gmail and retrieve emails based on predefined parameters.  
- **Phishing Detection**: Employs a machine learning algorithm to examine and identify phishing attempts.  
- **Interactive Web Interface**: Developed with Flask, offering a seamless platform for entering credentials, retrieving emails, and presenting results in a well-organized table.
